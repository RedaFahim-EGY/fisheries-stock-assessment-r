# Module 07 — Integrated assessment-readiness review

This module synthesizes the evidence developed in Modules 02–06 into an explicit pre-assessment decision framework.

It does **not** fit a stock-assessment model. Instead, it asks whether each evidence domain is scientifically defensible for later use and classifies it as **supported**, **usable with caveats**, **usable with sensitivity**, or **unresolved / not recommended**.

## Main questions

- Is there enough support for each information source?
- Are observations comparable through time and space?
- Could monitoring, fleet, gear, reader or sampling changes create apparent biological signals?
- Are life-history inputs traceable and transferable to the target stock and period?
- Which uncertainties must be propagated as sensitivity analyses?
- Are there unresolved evidence gates that should prevent model fitting?

## Outputs

The workflow builds:

- an integrated evidence register;
- transparent readiness classifications;
- a follow-up priority score used only for scientific triage;
- an evidence-dimension heatmap;
- generic assessment-input gates;
- a scenario matrix showing which increasingly demanding analyses are currently supportable;
- a sensitivity register to carry uncertainty forward;
- an explicit stop/go statement.

## Files

- `07_assessment_readiness.R` — reproducible synthesis and decision logic.
- `index.qmd` — Quarto scientific narrative and rendered diagnostics.

The evidence register is intentionally transparent and editable. Ordinal scores are not statistical weights and should never replace expert review or source-specific diagnostics.
